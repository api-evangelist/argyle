Argyle is an employment data connectivity platform offering a REST API for accessing payroll records, employment history, income verification, and gig platform earnings via user-consented direct-source connections. The API provides real-time access to standardized payroll data across traditional employers, gig platforms, and government payroll systems, with webhook alerts for employment and income changes.

**Areas:** Employment Data · Payroll · Income Verification · Gig Economy · Financial Data · Employment History · Earned Wage Access · Direct Deposit

## How this profile is made

API Evangelist profiles a company's public API surface the way a developer would find it: the website, developer portal and documentation, the specifications it publishes, its public repositories, and its pricing, status and changelog pages. From that it derives the properties above — contracts split per API, workflows, schemas, collections, governance rules, plans and rate limits — and scores them against the published [Kin Score rubric](https://github.com/api-evangelist/kin-score).

The artifacts are published on [APIs.io](https://apis.io), not in this repository. This repository is the public record for Argyle: the place to say something is wrong, missing or out of date, and to ask for a re-score or a removal.
